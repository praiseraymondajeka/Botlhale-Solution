# Botlhale Solutions Nigeria

The site is built with Next.js App Router, TypeScript, Tailwind CSS, and shadcn/ui component conventions.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Routes

- `/` — Home
- `/about` — About BSA
- `/service` — Services
- `/contact` — Contact and consultation

Shared UI components live in `components/ui`; add further shadcn/ui components with the shadcn CLI.
